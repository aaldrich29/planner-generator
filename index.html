Planner Generator

A free tool for generating printable paper planner pages. Everything runs in your browser — nothing is uploaded, no account needed. Pick a page type, set the date or project, then print it or save it as a PDF.

How it works
  1. Pick a page from the left sidebar — daily slips, weekly command center, project dashboards, meeting notes, habit trackers and more.
  2. Set the parameters in the top bar. The controls change with the page: date, week, project name, time range, and so on. The preview updates as you type.
  3. Print one page with Print / Save PDF — or click + Queue to stack up several pages and print them all in one job.
Worth knowing
  • Pages are letter size (8.5″ × 11″). In your browser's print dialog, set margins to None and scale to 100%.
  • The Margin setting shifts the binding edge for left- or right-hand pages in a binder.
  • Star any page (★) to pin it to Favorites. Your accent color, name, favorites and saved queues are remembered on this device.
